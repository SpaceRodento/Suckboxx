# Yöajon loki

Yksi rivi jokaisesta yöajosta, uusin alimpana. **Yöajo lisää oman rivinsä ennen
lopettamista** omaan PR:äänsä ([PROMPTI.md](PROMPTI.md) Y14). Rutiini merkitään ajetuksi,
vaikkei se tuottaisi mitään, joten tämä tiedosto on ainoa jälki repossa: **rivin puuttuminen on
itsessään tulos.** Päiväistunto kirjoittaa tänne myös omat jonoa koskevat rivinsä.

Rivi on hakemisto, ei raportti: päivä, tunnus, yksi tulossana (`valmis` / `osittain` /
`estynyt` / `tyhjä`) ja yksi lause, jota PR:n otsikko ei kerro. Yksityiskohdat kuuluvat PR:ään.
Tulossolu enintään 400 merkkiä.
